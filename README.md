# LAST STAND
### 2D Action Platformer | Unity | C#

**Last Stand** is a 2D action platformer where the player takes the role of a police officer fighting against terrorists to secure the city.

The game focuses on combat, enemy encounters, platforming challenges, and a final objective to complete the mission.

## 🎮 Game Overview

- **Genre:** 2D Action / Platformer
- **Engine:** Unity
- **Language:** C#
- **Platform:** PC
- **Game Mode:** Single Player
- **Developer:** Fireloop Interactive

## ⚔️ Gameplay Features

- 2D side-scrolling action gameplay.
- Police officer as the main playable character.
- Combat against terrorist enemies.
- Enemy patrol and attack behavior.
- Gun-based combat system.
- Player health and damage system.
- Coin collection mechanic.
- Health restoration through collected coins.
- Opening and ending cutscenes.
- Final victory objective.

## 👾 Enemy System

Enemies patrol their assigned areas and attack the player using different attack behaviors.

The player must defeat all enemies to complete the mission.

## 🪙 Coin System

Coins can be collected during gameplay.

Collecting 5 coins restores 10% of the player's health when health is below maximum.

## 🎬 Cutscenes

The game includes:

- **Opening Cutscene:** Introduces the situation and the conflict between the police and terrorists.
- **Ending Cutscene:** Plays after defeating all enemies and leads the player toward the victory flag.

## 🎯 Main Objective

Defeat all enemies, survive the combat encounters, and reach the victory flag to complete the mission.
